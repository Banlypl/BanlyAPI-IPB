<h1 align="center">Banly dla Invision Community</h1>

<p align="center">
  Widget do sidebara. Wpisujesz SteamID, dostajesz liczbę sieci z aktywnym banem<br>
  i od razu link do pełnego wyniku na Banly.pl.
</p>

## Co widzi użytkownik

- logo Banly, dopasowane do ciemnego i jasnego sidebara
- pole na SteamID, SteamID64 albo link do profilu Steam
- awatar, nick i liczbę sieci z aktywnym banem
- link „Szczegóły na Banly.pl”, który otwiera pełne sprawdzenie

## Instalacja

1. W panelu administratora zainstaluj aplikację **Banly**.
2. Otwórz zakładkę **Banly** i wklej klucz API.
3. W edytorze bloków sidebara dodaj **Banly Checker**. Blok jest w grupie Banly i działa w sidebarze oraz w Pages.

## Klucz API

Po klucz zgłoś się do [mT](https://discord.com/users/411086675998015488).

Nigdy nie udostępniaj swojego klucza.

## Wymagania

Invision Community 4.7.

## Modyfikacja

Wygląd możesz zmienić w CSS motywu. Klasy:

```
.banlyWidget__row
.banlyWidget__input
.banlyWidget__btn
```
